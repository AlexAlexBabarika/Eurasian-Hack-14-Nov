# ProveryAI web

Next.js 15 (App Router) + Tailwind v4 + shadcn/ui. Run `pnpm dev` (or `make web` from the repo root); the API must be on `NEXT_PUBLIC_API_URL` (default `http://localhost:8000`).

`src/lib/api-types.ts` is generated from the FastAPI schema: run `make types` from the repo root, never edit by hand.

Two cached audits are bundled at build time (`src/lib/examples.ts`) and regenerated by `make sample`, so the example reports open without the API:

- `/audit/demo-fixture` renders `api/data/audits/demo-fixture.json`: the demo product with its original policy.
- `/audit/demo-fixture-fixed` renders `api/data/audits/demo-fixture-fixed.json`: the same product after the policy fix. The landing page links to it with `?before=demo-fixture`, which shows it as a before/after comparison.
